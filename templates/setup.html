Initial configuration

Set up your PKI

Create your first administrator and configure your organization. Remote initial setup is available directly over HTTPS; no SSH tunnel is required.

Before setup, anyone who can reach this service can create the first administrator. Restrict access to your management network with a firewall until setup is complete, and verify the server certificate fingerprint through a trusted channel before entering credentials. Setup closes permanently after the first administrator is created.

Already have a backup? Restore an existing installation through localhost or an SSH tunnel before creating an administrator. Remote setup does not enable remote backup recovery.
